## Overview

The Aurora Hero is designed to immediately capture user attention. By combining complex CSS gradients with Framer Motion's fluid spring physics, it creates a "living" background that reacts subtly to mouse movement without overwhelming the typography.

> **Design Tip:** Always pair this component with highly legible, high-contrast foreground text. If your brand colors are light, ensure the aurora opacity is kept below `40%`.

## Installation

Run the following command to add this component to your project:

```bash
npx satis-ui add aurora-hero
```

## Features

This component isn't just visually appealing; it's engineered for performance and DX:

- **Zero Canvas/WebGL:** Completely DOM and CSS-based for maximum compatibility.
- **Prefers Reduced Motion:** Automatically respects the user's OS-level accessibility settings.
- **Intelligent Layout:** Built-in responsive breakpoints ensure it looks perfect from mobile to ultra-wide displays.

## Component API

The `AuroraHero` component accepts several props to customize the magnetic pull and color palette. This table demonstrates our newly engineered **Card-in-Card** UI design.

| Prop                | Type        | Default                  | Description                                                                   |
| :------------------ | :---------- | :----------------------- | :---------------------------------------------------------------------------- |
| **`title`**         | `ReactNode` | `undefined`              | The primary `h1` heading. Accepts plain text or complex React nodes.          |
| **`description`**   | `string`    | `""`                     | The secondary subtitle text rendered below the main heading.                  |
| **`colors`**        | `string[]`  | `["#ff0055", "#00ff99"]` | Array of hex codes used to generate the fluid gradient mesh.                  |
| **`magneticForce`** | `number`    | `0.5`                    | The multiplier for the mouse-tracking parallax effect. Set to `0` to disable. |
| **`blurStrength`**  | `number`    | `60`                     | The `backdrop-blur` value (in pixels) applied to the foreground glass layer.  |
| **`animateOnLoad`** | `boolean`   | `true`                   | Whether the aurora should fade in smoothly when the component mounts.         |

## Usage Example

Here is how you compose the Aurora Hero with standard buttons and layout constraints:

```tsx
import { AuroraHero } from "@/components/ui/aurora-hero"
import { Button } from "@/components/ui/button"

export default function Page() {
  return (
    <AuroraHero
      title={
        <span>
          Ship products <br className="hidden sm:block" />
          <span className="text-primary">faster than ever.</span>
        </span>
      }
      description="The ultimate UI kit for modern startups."
      colors={["#3b82f6", "#8b5cf6", "#ec4899"]}
      magneticForce={0.8}
    >
      <div className="mt-8 flex flex-col items-center gap-4 sm:flex-row">
        <Button size="lg" className="rounded-full">
          Get Started
        </Button>
        <Button size="lg" variant="outline" className="rounded-full">
          Read the Docs
        </Button>
      </div>
    </AuroraHero>
  )
}
```

## Accessibility

We take web standards seriously. The background animations are automatically disabled if the user has requested reduced motion at the OS level:

```css
@media (prefers-reduced-motion: reduce) {
  .aurora-mesh {
    animation: none;
    transform: none;
  }
}
```
