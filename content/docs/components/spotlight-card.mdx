This is the exact interaction seen in the "Playgrounds" view of our reference design. It uses `useMotionTemplate` from Framer Motion to inject `clientX` and `clientY` coordinates directly into a CSS `mask-image`.

### The Physics

We avoid standard CSS `:hover` for this effect because it cannot track coordinates. Instead, we listen to `onMouseMove` at the grid level and pass the coordinates down via context or custom properties.
