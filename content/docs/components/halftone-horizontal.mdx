_Note: This component utilizes pure Canvas API. No WebGL or Three.js dependencies are required._

## Props

| Prop                   | Type              | Default     | Description                                                               |
| :--------------------- | :---------------- | :---------- | :------------------------------------------------------------------------ |
| **`imageUrl`**         | `string`          | —           | The source URL of the image to display.                                   |
| **`lines`**            | `number`          | `90`        | Number of horizontal rows. Higher = more vertical detail.                 |
| **`pointsPerLine`**    | `number`          | `180`       | Resolution points across each line. Higher = smoother curves.             |
| **`maxLineThickness`** | `number`          | `0.85`      | Max thickness multiplier of the lines relative to their vertical spacing. |
| **`contrast`**         | `number`          | `1.4`       | Contrast curve for the thickness. Higher = darker shadows.                |
| **`hoverRadius`**      | `number`          | `180`       | Radius of the mouse interaction in pixels.                                |
| **`mouseForce`**       | `number`          | `0.15`      | Force applied by the mouse Y-velocity to push the strings.                |
| **`stiffness`**        | `number`          | `0.015`     | Spring stiffness (tendency to return to horizontal origin).               |
| **`friction`**         | `number`          | `0.92`      | Velocity damping/friction (how quickly it settles).                       |
| **`tension`**          | `number`          | `0.25`      | Tension between horizontal points on the same string.                     |
| **`fallback`**         | `React.ReactNode` | `null`      | Optional fallback UI rendered while the image loads.                      |
| **`className`**        | `string`          | `undefined` | Standard React classNames for the container wrapper.                      |
