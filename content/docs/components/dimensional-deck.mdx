## Props

| Prop                    | Type       | Default    | Description                                              |
| :---------------------- | :--------- | :--------- | :------------------------------------------------------- |
| **`images`**            | `string[]` | _Required_ | Array of image URLs to load into the deck.               |
| **`cardWidthRatio`**    | `number`   | `0.35`     | Percentage of screen width the card occupies on desktop. |
| **`cardAspectRatio`**   | `number`   | `1.4`      | Width-to-height ratio of the cards.                      |
| **`scrollSensitivity`** | `number`   | `0.04`     | How heavily the scroll wheel affects movement.           |
| **`lerpFactor`**        | `number`   | `0.08`     | How buttery smooth the momentum is (0.01 to 1).          |
| **`bendMultiplier`**    | `number`   | `0.15`     | How much the cards bend physically when moving fast.     |
| **`rgbSplitStrength`**  | `number`   | `0.003`    | The intensity of the kinetic RGB color splitting.        |
| **`stackSpacing`**      | `number`   | `1.2`      | Space between cards in relation to viewport height.      |
| **`tiltMultiplier`**    | `number`   | `0.08`     | How much cards tilt backwards as they stack.             |
