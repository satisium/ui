## Props

| Prop                       | Type                 | Default     | Description                                                      |
| :------------------------- | :------------------- | :---------- | :--------------------------------------------------------------- |
| **`images`**               | `MarqueeImage[]`     | _Required_  | Array of image objects to render in the marquee.                 |
| **`cardWidth`**            | `number`             | `384`       | Width of each card in pixels.                                    |
| **`cardHeight`**           | `number`             | `288`       | Height of each card in pixels.                                   |
| **`gap`**                  | `number`             | `-160`      | Negative gap between cards for overlap.                          |
| **`defaultVelocity`**      | `number`             | `1.0`       | Base scroll speed multiplier.                                    |
| **`maxSkew`**              | `number`             | `15`        | Maximum skew angle in degrees based on velocity.                 |
| **`dragFactor`**           | `number`             | `1.2`       | Multiplier for drag-to-scroll sensitivity.                       |
| **`pauseOnHover`**         | `boolean`            | `true`      | Pauses auto-scroll when hovering a card.                         |
| **`enableEntry`**          | `boolean`            | `false`     | Enables cinematic entry animation from off-screen.               |
| **`entryAnimationDelay`**  | `number`             | `0.5`       | Delay in seconds before the entry animation starts.              |
| **`entryAnimationDuration`** | `number`           | `2.5`       | Duration in seconds for the entry animation.                     |
| **`entryDistance`**        | `number`             | `2000`      | Starting distance in pixels for the entry animation.             |
| **`enableWave`**           | `boolean`            | `true`      | Enables the vertical wave effect on hover.                       |
| **`waveHeight`**           | `number`             | `40`        | Maximum vertical lift of the hovered card in pixels.             |
| **`waveProximity`**        | `number`             | `2`         | How many neighboring cards are affected on each side.            |
| **`waveSpringConfig`**     | `{ stiffness, damping }` | `{ stiffness: 300, damping: 25 }` | Spring physics for the wave vertical lift. |
| **`className`**            | `string`             | `undefined` | Standard React classNames for the container wrapper.             |
