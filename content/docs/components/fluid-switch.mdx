## Overview

The Fluid Switch is designed to replace the standard HTML checkbox. We use `motion/react` to apply spring physics to the thumb, giving it a subtle squish effect when tapped, mimicking the tactile feedback of a physical hardware toggle.

## Installation

Run the following command to install the component into your project. Note that it requires `motion` to be installed.

```bash
npx shadcn@latest add https://satis-ui.com/r/fluid-switch.json
```
