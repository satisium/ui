Buttons should feel tangible. When the user hovers over this button, it creates a subtle magnetic pull towards the cursor, increasing click confidence.

### Usage

```tsx
import { MagneticButton } from "@/components/ui/magnetic-button"

export default function App() {
  return <MagneticButton>Hover me</MagneticButton>
}
```
