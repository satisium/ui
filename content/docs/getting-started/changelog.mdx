# Changelog

## v3.0.0

**August 15, 2026** <Badge className="bg-amber-500/10 text-amber-500 hover:bg-amber-500/20 transition-colors border-none -translate-y-[2px] ml-2 font-bold tracking-wider uppercase text-[10px] px-2 py-0.5">Beta</Badge>

**Welcome to Satisium UI.**
Version 3 represents a complete rebranding and ground-up rewrite of our legacy library, _Satis UI_.

**A Completely New UI Collection**
The old v2 component collection has been officially deprecated and replaced. Satisium UI features an entirely new, vastly superior collection of components built with advanced physics and rendering techniques.

**Still Native to Shadcn**
While the components are completely different, the developer experience you love hasn't changed. Satisium UI is still built natively for the `shadcn` ecosystem, allowing you to install components and their dependencies seamlessly via the CLI.

**What does Beta mean?**
The core physics engines and components are highly stable (currently on `v3.0.0-beta.61`). However, as we gather feedback, some component APIs may undergo minor refinements before the final stable release.

### The Mega Release

This landmark release introduces **54 new core components** and dozens of pre-built demo variants.
