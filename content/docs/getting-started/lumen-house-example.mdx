## A complete Skills-built studio

Lumen House is a five-route photography studio that demonstrates the complete Satisium UI Skills workflow in a working product. Browse the embedded site below, then open it in a new tab when you want the full screen experience.

<LumenHouseExamplePreview />

## What to inspect

The example includes a Home route, Showcase, Services, Journal, Contact and a compatibility `/work` alias. It uses the same white, muted-gray, orange and rounded surface system as Satisium UI, with Plus Jakarta Sans for its interface and IBM Plex Mono for metadata.

Its **View build plan** control exposes the reproducible `LumenHousePlan/` folder. The linked package includes the source project, ten plan files, the approved 45-second site-tour MP4 and its poster so a coding agent can reproduce the studio without regenerating the film.

## Use the same workflow

Start with [Skills](/docs/getting-started/skills) to install the workflow instructions, then follow the supplied plan from its README through QA. The studio remains a worked example rather than a template or an additional installable component.
