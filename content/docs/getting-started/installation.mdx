Getting started is designed to be frictionless. We assume you are running the latest version of Next.js and Tailwind v4.

### Prerequisites

You will need the following installed:

- `next` (latest)
- `tailwindcss` (v4)
- `motion-react` (for our precise spring physics)
- `zustand` (for decoupled spatial state)

```bash
npm install motion-react zustand
```
